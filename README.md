# Scanner B3 para iPad

Aplicação web instalável para análise assistida de oportunidades de swing trade.

- Consulta dados públicos online da B3.
- Analisa contexto diário e confirmação de 60 minutos.
- Não envia ordens automaticamente.
- Registra decisões apenas no dispositivo do usuário.
- Não constitui recomendação de investimento.
